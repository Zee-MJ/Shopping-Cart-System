**SKZOO SHOPPING SYSTEM BY SANTOS, BSIT 1-2 [] Programming**

This program is a console-based Shopping Cart System themed around SKZ merchandise. It allows users to browse products, search items by name, filter by category, and add products to a shopping cart with quantity tracking and stock validation.

The system includes a cart management feature where users can view their cart, update item quantities, remove items, and clear the cart before checkout. During checkout, the program calculates the total cost, applies discounts if applicable, validates payment, and computes change.

An enhanced receipt system generates a detailed transaction record that includes a receipt number, date and time, purchased items with quantities, original total, discount, final total, payment, and change.

The program also includes a low-stock alert system that notifies when product inventory reaches a critical level, and an order history feature that stores completed transactions during runtime for later viewing.

Overall, the system demonstrates the use of arrays, objects, classes, input validation, stock management, and basic data handling to simulate a functional shopping experience.

AI was used as a support tool during the development of this project. It helped mainly with understanding the code and the flow of the program such as input validation, cart logic, and checkout processing.
AI assistance was used to clarify how certain parts of the system should work, especially in managing product selection, improving error handling, cart limitations and stock system. It was also used to help structure the flow of the program and suggest improvements for stability and usability.

Some questions asked were:
- How to add a user validation if user types a letter?
- How to add cart limitation and validation if user exceeds limit
- How to add Discount in C#
- How to set up commit in Github

After receiving suggestions, the code was reviewed, modified, and adjusted to fit the project requirements and to ensure that it works correctly with the rest of the program.
